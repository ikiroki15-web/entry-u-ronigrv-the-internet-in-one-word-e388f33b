Entry for the make.fun competition
[The Internet in One Word](https://make.fun/competitions/u-ronigrv-the-internet-in-one-word-e388f33b).

`main.ts` writes a single word — **Doomscroll** — to `/output/entry.txt`.
It is the whole internet in one word: the grim, endless scroll through bad
news that nobody can stop doing, funny because "doom" is heavy and dramatic
while "scroll" is the most mundane gesture on earth, and true of every feed
on every platform, not just one app.

Run it with Node 22+:

```sh
node main.ts
```
